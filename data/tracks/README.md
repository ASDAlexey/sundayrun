# GPS-записи трассы

Сюда складываются GPX-записи забега — по одной на дату, `ГГГГ-ММ-ДД.gpx`. Чем их больше, тем
надёжнее ответ на вопрос «сколько на трассе на самом деле метров»: одна запись — это одно мнение
приёмника, десяток — уже измерение.

Замер: `npm run measure-course`

Скрипт печатает по каждой записи три длины и раскладку по кругам, а снизу — медианы. Записи, не
похожие на забег (длинная тренировка, разминка), он отбрасывает сам.

Три числа — не придирка, они отвечают на разные вопросы:

- **сырая** — сумма расстояний между трекпоинтами;
- **сглаженная** — то же, но каждая точка усреднена с соседом. Шум приёмника длину только
  добавляет, никогда не отнимает, поэтому это потолок: больше на трассе быть не может;
- **по часам** — одометр из `gpxdata:distance`, то есть ровно та цифра, которую бегун видел на
  запястье. Часы мешают спутники с датчиками движения и заметно завышают.

Что известно на сегодня (две записи, 2026-07-26 и 2026-08-30):

|               | сглаженная | сырая  | по часам    |
| ------------- | ---------- | ------ | ----------- |
| вся дистанция | 4997 м     | 5016 м | 5045 м      |
| большой круг  |            | 2304 м | 2305…2336 м |

То есть трасса — ровно те 5 км, которые клуб и объявляет. Ощущение, что круг «на самом деле 2350»,
берётся из колонки «по часам»: сами часы в один из забегов насчитали круг 2336 м. Пока медиана
сглаженной длины не сдвинется, расчёты темпа на сайте остаются на объявленных 5 км и 2,3 км.

**Файлы личные.** В GPX от часов лежат отметки времени, пульс и каденс — репозиторий публичный,
так что перед коммитом стоит решить, готов ли автор записи их показывать.
